# Square for Restaurants Connector — Preparation

**Category:** C46. Restaurant / Hospitality Point-of-Sale (POS)  
**Vendor URL:** https://squareup.com/us/en/point-of-sale/restaurants  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Square for Restaurants** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C46. Restaurant / Hospitality Point-of-Sale (POS)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **управляющий ресторана** сталкивается с задачей: **ресторанный учет, синхронизация онлайн-заказов с залом, управление технологическими картами и чеками**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Square for Restaurants переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **управляющий ресторана, бухгалтер, кассир**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `создание ресторанного заказа -> расчет налогов и скидок -> проведение платежа -> печать фискального чека`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Square for Restaurants.
